#
# 来源：windows-rs 仓库 crates/libs/reactor-setup/assets/runtime.txt
#       @ a48e42ebe507985f2f474c4007fe8db2141371a4
#       （即上游 windows-reactor-setup 内置的运行时清单）
# 用途：scripts/build-installer.ps1 从 Microsoft.WindowsAppSDK.Runtime 的
#       nupkg -> MSIX 里按本清单抽取文件，组装安装包的 staging 目录。
#
# 规则：
# - 以 # 开头的行是注释，忽略；
# - "=== xxx ===" 是分段标记，决定该段条目是必需还是可选；
# - 每行一个条目，与 MSIX 内的顶层名称比对时忽略大小写
#   （MSIX 里是 af-ZA / ca-Es-VALENCIA 这类混合大小写，清单统一写小写）；
# - 条目是文件还是目录由 MSIX 里的实际形态决定，不用名字带不带点去猜
#   （Microsoft.UI.Xaml 本身就带点）。
#
# required 段：必需。缺任何一个都直接打包失败 —— 自包含模式下少一个 DLL
#   或 .pri 就会「窗口创建失败后静默退出」。
# optional 段：可选。缺了只是少了该语言的界面文案，不阻断打包
#   （不同 WindowsAppRuntime 版本收录的语言不完全一样）。
#
# 换运行时版本时：
#   1. 改 installer/runtime-version.txt 里的版本号；
#   2. 跑 scripts/build-installer.ps1，脚本会校验 required 段逐条命中，
#      optional 段缺失只给提示；绝不会产出"装完缺关键文件"的坏包；
#   3. 若新版本增删了必需文件，按报错提示同步更新本清单。
